# omhandball.fr — Refonte WordPress

Projet de refonte du site de l'Olympique Mehun Handball (Mehun-sur-Yèvre) :
passage de Joomla 5 (hébergement LWS) à WordPress, avec un thème sur mesure
moderne inspiré du logo du club.

- `omhb-theme/` — thème WordPress sur mesure (voir `omhb-theme/README.md`)
- `omhb-theme.zip` — thème prêt à téléverser dans WordPress
- `contenus/` — contenus des 7 pages, prêts à coller
- `GUIDE-INSTALLATION.md` — guide complet pas à pas (installation LWS, thème,
  plugins, migration Joomla, bascule du domaine, SEO)

Palette aux couleurs du logo officiel : rouge `#cc1517` / anthracite / blanc, modifiable
dans le Customizer sans toucher au code.
