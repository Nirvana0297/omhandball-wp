# Aperçu du futur site

Trois façons de visualiser le design du nouveau site **avant installation** :

## 1. Aperçu interactif (recommandé)

Ouvrez `apercu.html` dans votre navigateur :

1. Sur GitHub, ouvrez `apercu/apercu.html` puis le lien
   **htmlpreview.github.io** proposé dans la barre d'outils « Preview »,
   ou collez cette adresse dans votre navigateur :

   https://htmlpreview.github.io/?https://github.com/Nirvana0297/omhandball-wp/blob/vibe/refonte-wordpress-95f45b/apercu/apercu.html

2. Ou téléchargez le dossier `apercu/` en entier (les 4 fichiers) et ouvrez
   `apercu.html` en local.

Cet aperçu utilise **le vrai CSS du thème** (`style.css`) et le vrai logo :
- redimensionnez la fenêtre pour voir le comportement mobile/tablette,
- le menu burger fonctionne,
- les couleurs sont celles du logo officiel (rouge `#cc1517`).

Les photos d'actualité sont remplacées par des aplats de dégradé, et la
bannière n'a pas encore d'image de fond (elle sera choisie dans le Customizer).

## 2. Maquettes

- `maquette-ordinateur.png` — structure de l'accueil sur grand écran
- `maquette-mobile.png` — structure sur téléphone

## 3. Aperçu réel

Une fois WordPress installé chez LWS avec le thème (guide
`../GUIDE-INSTALLATION.md`), le site sera visible sur
`https://omhandball.fr/wp/` avant la bascule du domaine.
